# Go Web Server

A simple web server implementation using Go's standard libraries.

## Features

- HTTP server implementation
- RESTful API endpoints
- Static file serving
- Basic routing functionality

## Usage

1. Start the server:

```bash
go run main.go
```

The server will start on `localhost:8080` by default.

2. Access the server:

Open your browser and navigate to `http://localhost:8080`.

3. Explore the API endpoints:

- GET `/` - Returns a simple "Hello, World!" message

- GET `/hello` - Returns a simple "welcome to my website" message

- POST `/form` - Returns a simple "Post request Successfull" message
